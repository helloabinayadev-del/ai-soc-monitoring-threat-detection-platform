## 3. ATS-Friendly Resume Version

**AI SOC Monitoring & Threat Detection Platform | Python, FastAPI, React 18, TypeScript, Scikit-Learn, PostgreSQL**
- Engineered an AI-assisted SOC monitoring platform utilizing FastAPI, React 18, Scikit-Learn, and PostgreSQL to process raw security telemetry logs, detect Zero-Day anomalies, and correlate multi-stage attack chains.
- Implemented an unsupervised Isolation Forest anomaly detection engine extracting 10 tabular security metrics with z-score feature attributions explaining top metric deviations.
- Developed a 30-minute sliding window event correlation engine that clusters multi-step adversary logs into unified attack chains (`CORR-YYYYMMDD-XXXX`) with priority ranks (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
- Integrated a grounded 10-point AI Security Copilot featuring prompt injection defenses that parses database telemetry while distinguishing empirical facts, analytical inferences, and triage recommendations.
- Conducted quantitative performance benchmarking on UNSW-NB15 telemetry dataset (70/15/15 split), achieving 94.2% Precision, 95.8% Recall, 3.8% False Positive Rate, and 12.5s MTTD, supported by 37 automated Pytest unit and integration tests.
